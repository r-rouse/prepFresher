# Interview Prep & Engineering Refreshers

This repository is a collection of my ongoing interview prep, technical
refreshers, and learning notes.

The goal is to keep everything I am reviewing in one place so I can
build on previous sessions, revisit concepts I have not used in a while,
and track my understanding over time.

## Topics

### JavaScript & React

Notes and practice covering JavaScript fundamentals and React concepts,
including:

-   JavaScript fundamentals
-   Scope, closures, and the event loop
-   Objects, references, and immutability
-   Array methods
-   Async JavaScript
-   React state and rendering
-   Hooks
-   Component behavior and performance
-   Common interview questions and debugging exercises

### System Design

Notes and exercises focused on building a stronger understanding of how

-   APIs

-   Replication
-   Scaling
-   Reliability and fault tolerance

-   System design interview exercises

## Why This Repo Exists

A lot of engineering knowledge is use-it-or-lose-it. Some concepts are
part of my everyday work, while others may go months or years without
coming up.

This repo is my place to keep those concepts fresh.

Rather than trying to create polished tutorials, these notes are meant
to document the process of learning and relearning: questions I got
wrong, concepts that needed clarification, useful mental models, code
examples, and things I want to remember the next time I encounter them.

Over time, the goal is for this repository to become a practical
reference for React, JavaScript, system design, and AI engineering that
reflects how my understanding develops through continued practice.
